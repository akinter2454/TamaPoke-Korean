Base: v3.99.0

ROOT CAUSE
- v3.98.1 added uiRoundTextWidth()/uiDrawCenteredFit() near the top of TamaPoke.ino.
- Those helpers referenced CY/CX before the later #define CY 233 / #define CX 233 lines.
- Arduino/G++ therefore failed in GitHub Actions with: 'CX was not declared in this scope'.

FIX
- CX and CY are now declared immediately after FW_VERSION, before every UI text helper.
- The later duplicate definitions were removed.
- Both TamaPoke.ino and firmware_source/TamaPoke.ino contain the same fix.
- verify_ui_geometry_declaration_order_v3991.py was added to GitHub Actions before the real Arduino compile step.
