TamaPoke 한국어판 v3.99.0

이번 버전은 v3.98.1을 기준으로 디지몬 Shiny 시스템을 추가한 기능 업데이트입니다.

핵심 변경
- 디지몬도 디지타마 생성 시 기존 Shiny 확률을 사용합니다.
- 좋은 이별/반짝부적의 다음 알 Shiny 보정이 디지몬에도 적용됩니다.
- 샤이니열매가 현재 디지몬에도 사용됩니다.
- 별도 Shiny 스프라이트 없이 DGI RGB565 원본을 런타임 팔레트 변환합니다.
- 검은 외곽선과 흰 하이라이트는 보존하고 색상/중간 회색만 변환합니다.
- Shiny 상태는 진화, Jogress, 파티/박스, 배틀, 5개 키우기 슬롯에서 유지됩니다.
- 디지몬 도감에 Shiny 육성 기록을 별도 표시합니다.
- 새 NVS 키 digshy는 백업/복원 목록에 포함되어 기존 SAVE_VERSION 2와 호환됩니다.

기존 v3.98.1의 5개 키우기 슬롯, 배틀 이름 수정, 텍스트 경계 안전성은 그대로 유지됩니다.

대상 하드웨어:
- Waveshare ESP32-S3-Touch-AMOLED-1.75
- 466x466 CO5300 QSPI AMOLED
- CST9217 Touch

개발을 이어갈 때는 `TamaPoke-v3.99.0-HANDOFF.md`를 기준으로 사용하세요.
